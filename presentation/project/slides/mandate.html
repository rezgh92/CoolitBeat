What CoolIT did not publish

Pressure drop, heated area, paste identity, height, mass. We reconstructed them from the brief’s photographs and a calibrated model: about 120 cm², about 22 kPa, a skived split-flow copper core.

The rules we set ourselves

Conventional manufacturing, no printing. Same paste class and the same eight-thermocouple layout. Two test vehicles (117 and 100 cm²). Pressure drop at three boundaries. Five plates, three re-mounts, an independent repeat.

Source: CoolIT Systems tech brief, June 2026; reconstruction in docs/cooling/01-benchmark-and-requirements.md

CoolIT’s brief reports exactly one operating point and three numbers. Everything else about their plate is reconstructed, and we say so wherever a CoolIT-like number appears. The arbiter for any public claim is the OCP cold-plate test specification, whose primary author also wrote CoolIT’s brief, so we state every PRISM number the way that specification measures.
